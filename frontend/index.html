MiniC Analisador

Software educacional de compiladores. Linguagem analisada: subconjunto da linguagem C (MiniC).

Fases disponíveis: análise léxica (scanner) e análise sintática (parser e AST)

Como usar e o que é análise léxica

A análise léxica é a primeira fase de um compilador. O scanner lê o código caractere a caractere e o agrupa em tokens, que são as menores unidades com significado da linguagem. O trecho de texto que forma um token é chamado de lexema: em int numero = 10;, o lexema numero forma um token da categoria identificador, e o lexema 10 forma um literal inteiro. Espaços e comentários são descartados, e caracteres que não pertencem ao subconjunto são informados como erros léxicos, com linha e coluna.

  1. Escreva um programa ou selecione um dos exemplos.
  2. Clique em Analisar.
  3. Consulte a contagem, o código destacado por categoria, a tabela de tokens e a lista de erros.
  4. Use o passo a passo (botões ou setas esquerda e direita) para ver as transições do autômato que reconheceram cada token.

    Análise sintática e AST
    

      
    
        O que é análise sintática e AST
        
    A análise sintática é a segunda fase do compilador. O parser recebe a sequência de tokens do scanner e verifica se ela segue a gramática da linguagem, que define como os tokens podem ser combinados. Quando a sequência é válida, o parser constrói a árvore sintática abstrata (AST), uma representação em árvore da estrutura do programa.
    
        
    Há três estruturas que não se confundem. A sequência de tokens é o que o scanner reconheceu, em ordem. A árvore de derivação mostraria cada regra da gramática aplicada e todos os terminais, inclusive ; e os parênteses. A AST guarda só o que importa para o significado: em int x = (1 + 2) * 3;, os parênteses não viram nó (eles apenas mudam a forma da árvore) e o ; também não aparece; fica uma multiplicação cujo filho esquerdo é uma adição. Este projeto exibe a AST; não exibe a árvore de derivação.
    
      
    

      
    
        Gramática do MiniC (EBNF)
        
    programa        = { item } FIM ;
item            = declaracao | comando ;
declaracao      = tipo declarador { "," declarador } ";" ;
declarador      = IDENTIFICADOR [ "=" expressao ] ;
tipo            = "int" | "float" ;
comando         = atribuicao | condicional | bloco ;
atribuicao      = IDENTIFICADOR "=" expressao ";" ;
condicional     = "if" "(" expressao ")" bloco [ "else" ( bloco | condicional ) ] ;
bloco           = "{" { item } "}" ;
expressao       = aditiva [ op_relacional aditiva ] ;
op_relacional   = "==" | "!=" | "<" | "<=" | ">" | ">=" ;
aditiva         = multiplicativa { ( "+" | "-" ) multiplicativa } ;
multiplicativa  = unaria { ( "*" | "/" ) unaria } ;
unaria          = "-" unaria | primaria ;
primaria        = IDENTIFICADOR | LITERAL_INTEIRO | LITERAL_REAL | "(" expressao ")" ;
